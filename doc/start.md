教育的过程
尊重
学生和教师互相尊重，教师将学生视做完整，独立的人，学生有充分的自由和自主，教师引导学生遵守集体能够正常运转所需要的基本秩序。
一方面，这意味着教师不会居高临下发号施令，教师平等对待每一个学生，尊重并包容每一个学生的差异和个性。
另一方面，这也意味着教师不会过度保护和过度夸奖学生，在需要的时候，教师会坚决的引导学生走出舒适区，让学生自己面对问题和应对挑战，引导学生自我激励而不是依赖外部的夸奖和认可。
自主探索和学习，过程比结果更重要，慢即是快
自主探索和学习的过程比学到的知识结果更重要，更有价值。相比传统的教授知识的方式，我们更多的引导和鼓励孩子自己探索和学习，虽然这会花费更长的时间，但是这中间孩子建立的每一次尝试，每一次失败都有价值。更重要的是，学生会更加自信，能够更好的独立解决问题
走出舒适区才能成长
成长来自于不断突破自己的边界，获得更多的知识，解决更难的问题。人们倾向于待在自己的舒适区，走出舒适区不是一个自然会发生的事情，学生需要被刻意引导甚至施加一定的外界压力才能做到走出舒适区，所以，教师在某些情况下表现得很Tough是必要的，可能会像一个严苛的教练一样。
