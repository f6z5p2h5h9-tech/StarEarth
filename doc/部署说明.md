# 星与土（StarEarth）部署说明文档

## 项目概述

本项目是一个**纯静态前端 + Serverless API** 架构的 Web 应用。
- 前端：纯 HTML / CSS / JavaScript，无需构建步骤
- 后端 API：Node.js Serverless 函数（位于 `api/` 目录），需要运行时环境
- 数据库：Supabase（已配置，anon key 已内嵌在前端）

## 部署方案

### 方案一：推荐 —— Nginx 静态托管 + Node.js API（通用服务器）

适合已有 Linux 服务器（阿里云 ECS、腾讯云 CVM 等）。

#### 第一步：安装依赖

```bash
# 安装 Node.js 18+
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装 Nginx
sudo apt-get install -y nginx

# 安装 PM2（进程守护）
npm install -g pm2
```

#### 第二步：上传文件

将整个项目文件夹上传到服务器，例如 `/var/www/starearth/`

```bash
# 上传（在本地执行）
scp -r /path/to/StarEarth/* user@your-server-ip:/var/www/starearth/
```

#### 第三步：配置 Nginx

新建配置文件 `/etc/nginx/sites-available/starearth`：

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为实际域名或服务器 IP

    root /var/www/starearth;
    index index.html;

    # 静态文件直接服务
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 请求转发到 Node.js
    location /api/ {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/starearth /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

#### 第四步：启动 API 服务

在服务器的 `/var/www/starearth/` 目录下：

```bash
# 安装 Express（将 Vercel Serverless 函数包装为 Express 服务）
npm init -y
npm install express

# 创建服务入口文件（见下方 server.js）
# 然后用 PM2 启动
pm2 start server.js --name starearth-api
pm2 save
pm2 startup
```

**`server.js`** 内容（需要手动创建在项目根目录）：

```javascript
const express = require('express');
const app = express();
app.use(express.json());

// 模拟 Vercel 的 req/res 接口
function toVercel(handler) {
  return async (req, res) => {
    req.body = req.body || {};
    await handler(req, res);
  };
}

const { default: aiMarketing } = require('./api/ai-marketing.js');
const { default: generate } = require('./api/generate.js');
const { default: heartbeat } = require('./api/heartbeat.js');

app.all('/api/ai-marketing', toVercel(aiMarketing));
app.all('/api/generate', toVercel(generate));
app.all('/api/heartbeat', toVercel(heartbeat));

app.listen(3001, () => console.log('API server running on port 3001'));
```

#### 第五步：配置环境变量（关键！）

```bash
# 在服务器上设置环境变量
pm2 start server.js --name starearth-api \
  --env DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx

# 或者创建 .env 文件（使用 dotenv）
echo "DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx" > /var/www/starearth/.env
```

### 方案三：宝塔面板（最适合国内服务器运维）

1. 宝塔面板 → 网站 → 添加站点，根目录指向 `/www/wwwroot/starearth`
2. 上传所有文件
3. 安装 PM2 管理器，运行上方的 `server.js`
4. Nginx 配置同方案一的 `/api/` 反向代理

| 变量名 | 说明 | 获取方式 |
|--------|------|----------|

## 数据库表结构说明

Supabase 中已有以下数据表（由之前迁移创建）：

| 表名 | 用途 |
|------|------|
| `users` | 用户账户 |
| `courses` | 课程记录 |
| `topics` | 选题记录 |
| `ops_data` | 运营月度数据 |
| `ops_parent_leads` | 家长拓客 CRM |
| `ops_referrals` | 家长转介绍记录 |
| `settings` | 系统设置 |

> 如需在新 Supabase 项目中重建表，请运行 `supabase/migrations/` 目录下的 SQL 文件。

## 验证部署是否成功

部署完成后，逐项检查：

- [ ] 访问首页 `https://your-domain.com/` → 正常显示"星与土"
- [ ] 访问 `https://your-domain.com/ops-dashboard.html` → 运营看板正常
- [ ] 测试 AI 文案生成 `https://your-domain.com/ai-marketing.html` → 能生成内容（需 DeepSeek Key）
- [ ] 检查运营看板三个 Tab：📊 招生看板 / 👤 家长跟进 / 🤝 转介绍管理
